## Methodology note

Traces generated by Grok 4.1 fast non-reasoning (~15-20 high-level action
descriptions per trace). Commands classified into frontier-ops action schema
via keyword-based classifier. Not equivalent to live agent traces — a
Grok-based trace generator is used as a proxy for real agent behavior.
